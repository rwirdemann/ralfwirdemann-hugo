Das neue [Scheduled Release 0.3.1](https://github.com/rwirdemann/scheduled/releases/tag/0.3.1) enthält eine Reihe von kleineren Verbesserungen und Bugfixes, sowie ein größeres neues Feature: Task-Scheduling via Telegram. Neue Tasks können jetzt über einen Telegram-Chat von unterwegs eingestellt werden. Neue Tasks werden beim nächsten Start von Scheduled automatisch gepolled. Die Einrichtung des Features ist einfach und ist im [README.md](https://github.com/rwirdemann/scheduled/blob/main/README.md) beschrieben.
